# Security Policy

## Supported Versions

Security fixes are made on the latest released version. The `main` branch is
development code and may change without notice.

## Reporting a Vulnerability

Email `huntercbaldwin98@gmail.com` with the subject `crap security report`.
Do not include vulnerability details in a public issue.

Include the affected version, operating system, reproduction steps, impact,
and any suggested mitigation. Please allow time to investigate before public
disclosure.
